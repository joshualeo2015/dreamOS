# 🪐 DreamOS 🪐

> "Reviving legacy mobile hardware with pure minimalist design, electric energy, and vibrant user interfaces."

Welcome to **DreamOS**, a highly personalized, custom open-source design framework built explicitly to bring life back to legacy devices like the Motorola Moto E3 Power (Codename: `taoshan`). 

## ✨ Key Project Features

*   🎬 **Cinematic Startup:** Plays a smooth, 30fps custom vertical boot animation consisting of 150 high-definition frames optimized for 720x1280 screens.
*   🎨 **Signature Theme:** Replaces standard dull Android colors with a curated high-contrast palette featuring **Neon Pink**, **Electric Cyan**, **Vibrant Purple**, and **Deep Canvas Black**.
*   📱 **Stripped-Down Minimalist UI:** Built to optimize performance on legacy 1GB RAM chips by focusing solely on streamlined core communication layouts.
*   📡 **Hardware Integrations:** Configured native MediaTek MT6735 modem and RIL parameter hooks to keep physical SIM phone calling responsive.
*   📦 **Play Store Architecture Hooks:** Built-in repository vendor layouts ready to link the ultra-lightweight Google Play OpenGApps (Pico) platform.

## 🎨 System Interface Map

*   **Dialer:** Electric Blue pad buttons with a Neon Pink active dial command trigger.
*   **System UI & Sliders:** Dynamic high-contrast notification drop-down rails and pink volume active slider gauges.
*   **Lock Screen:** Features a massive, center-weighted signature glowing neon pink clock face.
*   **Keyboard:** A pitch-black tray configuration with character layouts bursting into a neon pink expand feedback bubble upon typing.
*   **File Manager:** Documents UI mapped with Cyan storage folders and Pink capacity progress indicators.
